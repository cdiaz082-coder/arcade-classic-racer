# Arcade Racer

Juego de carreras arcade táctico en vista superior (top-down), inspirado en los clásicos de laberinto con vehículos.

## Características

- **Físicas Arcade**: Manejo vectorial con inercia, aceleración y derrapes ligeros.
- **Generación Procedural**: Mapas con validación de conectividad (BFS) y distancias mínimas.
- **IA de Enemigos**: Varios comportamientos (Chaser, Interceptor, Blocker, Scout, etc.).
- **Mecánicas Tácticas**: Manchas de aceite, power-ups de invulnerabilidad y vidas extra.
- **Controles**: Teclado, Gamepad y controles táctiles virtuales.
- **Multiplataforma**: Web + Android (Capacitor). Preparado para Rork / iOS.

## Instalación

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
